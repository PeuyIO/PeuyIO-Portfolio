# PeuyIO Portfolio

Современный адаптивный сайт‑портфолио, разработанный на React + Vite + Tailwind CSS. Проект создан в минималистичном стиле с акцентом на удобство использования, плавные анимации и современный внешний вид. Сайт демонстрирует навыки frontend и backend разработки, а также может использоваться как персональная визитка разработчика или основа для собственного portfolio проекта.

## Preview

Минималистичный dark UI с плавной навигацией, адаптивной версткой и современным интерфейсом. Проект разработан как персональный сайт для демонстрации навыков Full Stack разработки, backend решений и современных web‑технологий. Сайт включает адаптивную верстку, анимированные элементы интерфейса, плавную навигацию между секциями, поддержку мобильных устройств и современный визуальный стиль с градиентным фоном и полупрозрачными стеклянными эффектами.
